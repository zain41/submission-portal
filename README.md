# Assignment Submission Portal

A Flask-based assignment submission portal that allows students to submit assignment URLs. The project includes automated testing using pytest, a GitHub Actions CI pipeline, automatic JSON test reporting to a local machine, and conditional GitHub Pages deployment.

## Prerequisites

- Python 3.10 or higher
- Git
- GitHub account
- ngrok (installed and authenticated)

## 1. How to Run the Application

Follow these steps to run the portal locally.

**Step 1: Clone the repository**

```bash
git clone https://github.com/zain41/submission-portal.git
cd submission-portal
```

**Step 2: Create a virtual environment**

```bash
python -m venv .venv
```

**Step 3: Activate the virtual environment**

For Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

For Git Bash:

```bash
source .venv/Scripts/activate
```

**Step 4: Install dependencies**

```bash
pip install -r requirements.txt
```

**Step 5: Start the Flask application**

```bash
python app.py
```

Open the application in your browser using the local URL displayed by Flask, usually:

```text
http://127.0.0.1:5000
```

## 2. How to Run Automated Tests

The project uses pytest to test the assignment submission functionality.

**Run all tests:**

```bash
pytest
```

The following test cases are included:

1. Valid Submission: Checks whether a complete submission is successfully saved.
2. Missing Registration Number: Checks whether the application rejects submissions with a missing registration number.
3. Invalid Submission URL: Checks whether an invalid URL is rejected and not saved.

The pytest-json-report package is used to generate test results in JSON format.

To generate a JSON test report manually:

```bash
pytest --json-report --json-report-file=report.json
```

## 3. How to Start the Local JSON Report Receiver

The project includes a custom HTTP receiver that accepts test reports from GitHub Actions and saves them locally.

**Step 1: Open another terminal in the project directory.**

**Step 2: Start the receiver:**

```bash
python receiver.py
```

The receiver will listen on:

```text
http://localhost:8000
```

Keep this terminal running while the CI pipeline executes.

When a report is received successfully, it will automatically be saved as:

```text
test-report.json
```

## 4. Configure ngrok Tunnel

GitHub Actions runs on a remote server, so it cannot directly access localhost on your computer.

ngrok is used to forward requests from GitHub Actions to the local report receiver.

**Step 1: Start the receiver first:**

```bash
python receiver.py
```

**Step 2: Open another terminal and start ngrok:**

```bash
ngrok http 8000
```

**Step 3: Copy the HTTPS forwarding URL generated by ngrok.**

Configure this URL in the GitHub Actions workflow or the corresponding GitHub repository secret used by your project.

Keep both the receiver and ngrok running during the demonstration.

## 5. GitHub Actions CI Pipeline

The project uses GitHub Actions for Continuous Integration.

Whenever code is pushed to the configured repository branch, the workflow:

1. Checks out the latest repository code.
2. Sets up the Python environment.
3. Installs project dependencies.
4. Executes automated pytest tests.
5. Generates the JSON test report.
6. Adds repository and pipeline information, including the commit SHA, branch, run ID, and timestamp.
7. Sends the completed report to the local HTTP receiver.
8. Saves the received report as test-report.json.
9. Automatically emails the JSON report to the developer for both passing and failing runs using GitHub Secrets.

The pipeline records both successful and failed test executions.

## 6. Conditional GitHub Pages Deployment

The project includes a static frontend inside the `docs/` directory.

GitHub Pages is used to publish the static version of the application.

The deployment job depends on the successful completion of the test job.

If all tests pass, the deployment job runs and publishes the updated website.

If any test fails, deployment is skipped, and the previously published version remains unchanged.
